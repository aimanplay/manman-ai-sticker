# 品牌视觉规范 · 慢漫的AI人

整套表情包的视觉基线。改配色、字幕或构图时改这一份，不动主流程。

## 一、角色资产

默认角色是「慢漫的AI人」的 Q 版形象：蓬松凌乱黑色短发、棕色大眼睛、白皙肤色、黑色连帽外套 + 白色 T 恤，胸前蓝色发光方块项链，左袖口蓝色发光方块徽章，精致 3D 渲染质感。

用户给的是别的图时，**保留用户图本身的形象与画风**，不要强行套用默认角色。角色设定图是后续所有精灵图的唯一参考，形象在这一步定死。

## 二、色板

| 用途 | 色值 | 说明 |
|---|---|---|
| 品牌主色 | `#111318` | 头发与外套的近黑 |
| 品牌强调 | `#2E7BFF` | 蓝色发光方块（项链 / 袖标） |
| 字幕填色 | `#FFFFFF` | 白字 |
| 字幕描边 | `#101010` | 黑边，粗体，宽度约字高的 8% |
| 贴纸描边 | `#FFFFFF` | 角色外圈白描边，480 尺寸下 6–8px |
| 抠图底色（默认） | `#FF00FF` | 纯品红，脚本识别效果最好 |
| 抠图底色（备选） | `#00FF00` | 角色含粉/紫/品红时换纯绿 |
| 预览卡底 | `#F5F6F8` | 暖白，圆角 22px 白卡片 |

**禁用**：白底、浅灰底、灰白棋盘格。白描边与白字幕会和背景一起被抠掉，实测损失可超 20%。若生图后端能直接出**真透明** PNG，则无需任何底色，跳过归一化步骤。

## 三、字幕规范

- 字数 ≤ 6 字，短句，去口语化；避「神器／炸裂／封神」等浮夸词
- 白字 + 黑粗描边，居中，位于格子**下方 12% 安全带**内
- 所有格子文字完全相同、位置一致；生成后用 `qa_check.py` 核对每格白字像素量
- 标点尽量少（省略号、波浪号容易被模型画歪）；「！」「？」可用
- 每格底部字幕之外不出现任何文字、logo、水印

## 四、精灵图提示词模板

网格按当前生图后端支持的比例选，格子尽量接近正方形：3:2 → 3×2（6 帧，默认）、1:1 → 3×3（9 帧）、16:9 → 4×2（8 帧）。模板里的 `{列}` `{行}` `{帧数}` 按实际替换。

```
参考图是这个{角色简述}的角色设定图：{发型、五官、服装、配饰、画风}。
用这个角色画一张表情包精灵图（sprite sheet）：画面平均分成{列}列×{行}行共{帧数}个等大的正方形格子，格子之间不画边框、不留空隙。
只画头部和上半身特写（头顶到腰部），角色占格子高度的70%以上，绝对不要画腿部、脚或全身站姿。
{帧数}格按从左到右、从上到下的顺序是一段连续动作：前 1/3 帧{动作一}；中间 1/3 帧{动作二}；最后 1/3 帧{动作三}。
每一格里角色的长相、发型、服装、配饰、大小和画风完全一致，都在格子正中，角色完整不裁切。
每一格底部都有同样的白字黑边粗体大字「{字幕}」，{帧数}格文字完全相同、位置一致，不能有错字，任何一格都不能漏掉字幕。
粗黑描边，干净的平涂上色，贴纸风格。
背景是一整块纯品红色（#FF00FF），平涂，没有渐变、阴影、地面、纹理、文字、水印或logo。除了字幕，画面里不要出现任何文字。
```

背景句二选一：能出真透明时用「除了角色、道具和文字，其余全部是透明背景」；不能或拿不准时用上面那句纯品红。

## 五、构图与动作

- **半身特写**：角色占格高 ≥ 70%，头顶留一点空间给问号／灯泡／感叹号
- **三幕式动作**：前 1/3 帧起势 → 中间 1/3 帧推进 → 最后 1/3 帧收尾，形成循环播放也顺的短动作
- **禁止措辞**：「整个人跳起来」「往后一跳」「全身站姿」「跑出画面只剩一阵烟」。实测这类描述会让模型改成全身小人构图，并漏画上排字幕
- **固定物**：桌子、笔记本电脑这类静止物在上下两排可能高度不一致，切帧脚本按画面下部对齐可消掉跳动
- **道具文字**：模型爱在电脑屏幕上加小字，介意就写「除了字幕，画面里不要出现任何文字」

## 六、节奏与导出

| 项 | 默认 | 备注 |
|---|---|---|
| 帧数 | 6（3×2） | 1:1 可 9（3×3）；16:9 可 8（4×2）；按后端支持的比例选 |
| 每帧时长 | 200ms | 220ms 用于总览 |
| 循环 | 无限 | `loop=0` |
| 尺寸 | 480 / 240 正方形 | 逐帧 PNG 保留原始裁切 |
| 透明 | GIF 1bit 透明 + APNG 半透明 | APNG 用于保留发丝边缘 |
| 对齐 | 按画面下 35% 字幕/脚部对齐 | 防播放跳动 |

## 七、品牌预览卡

`brand_preview.py` 输出 1200×915 暖白底（` #F5F6F8 `）预览：中文标题（脚本自动在 macOS / Windows / Linux 找系统中文字体，也可用 `--font` 指定）、副标题写规格、3 列白色圆角卡片放各表情首帧、每卡下方字幕标签、右下角署名「慢漫的AI人」。卡片不加阴影、不加渐变，保持干净。

## 八、验收清单

出图后逐项过一遍（`qa_check.py` 自动覆盖前 5 项）：

- [ ] 网格等大、接近正方形、无格线
- [ ] 每格字幕齐全且一致，无错字
- [ ] 角色是同一个，半身特写，非全身小人
- [ ] 背景为纯色 / 真透明（或已归一化）
- [ ] 右下角与设定图无平台水印
- [ ] 切帧后透明底干净、无紫边／绿边
- [ ] GIF 帧数正确、循环播放不跳动
- [ ] 480 / 240 / APNG 三种产物齐全
- [ ] 预览卡中文无乱码、署名正确
