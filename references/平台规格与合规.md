# 表情平台规格与合规

用户说要上架表情平台时读这一份。**平台规则会变，一切以平台后台当下的要求为准**，不要凭记忆写死数值。

## 一、上架前先查这几项

| 项 | 要确认什么 |
|---|---|
| 尺寸 | 表情主图的像素尺寸、是否必须正方形 |
| 大小 | 单个文件体积上限（静态图 / 动态图可能不同） |
| 帧数 | 动态表情的帧数上限与最短／最长时长 |
| 格式 | 接受 GIF、APNG 还是别的；透明通道是否允许 |
| 数量 | 一套专辑要求几个表情，是否有主图、缩略图、图标、横幅等配套物料 |
| 文案 | 字幕是否允许、有没有禁用词、是否要求中文规范 |
| 审核 | 审核周期、被拒常见原因、能否修改重提 |

本 skill 输出的 240 版本**不保证合规**：它是便利尺寸，不是平台规格。确定规格后，可用 `make_gif.py` 的输出帧重新合成，或按平台要求单独导出一版。

## 二、AI 生成素材注意

- 部分平台要求标注 AI 生成内容或提交原创性说明，投稿前查清楚
- 生成图可能带平台水印，本 skill 已在流程里清理；送审前再目视确认一遍无水印、无残留色块
- 中文字幕属于画面文字，检查有没有错字、异体字、被裁切
- 角色一致性：整套表情应是同一个角色，不能出现发型、服装、配饰漂移

## 三、授权

- 角色来自**自己的照片**或**自己原创的形象**：自用与发布都没问题
- 来自**他人照片**（亲友、明星）、**他人作品**（动漫形象、品牌吉祥物、别人的插画）：自己玩没问题，**公开发布或商业上架前必须取得授权**
- 涉及品牌 logo、商标、可识别的产品外观：先确认使用范围
- 拿不准时，交付时提醒用户先确认权利，不要替他判断「应该没事」

## 四、送审自检表

- [ ] 已查平台当下尺寸 / 大小 / 帧数 / 格式 / 数量要求，并按规格重新导出
- [ ] 每个动态表情循环播放顺滑、无跳动、无黑帧
- [ ] 透明底干净，在白底和深底上都看过一遍（白描边在白底上要能看清）
- [ ] 字幕零错字、所有格子完全一致、无多余文字
- [ ] 全套无平台水印、无 AI 工具残留标识
- [ ] 配套物料（主图 / 缩略图 / 图标 / 横幅）齐全且风格统一
- [ ] 角色与素材授权已确认
- [ ] 已按平台要求填写 AI 生成说明（如需要）
