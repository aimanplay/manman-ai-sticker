# 表情文案库 · 慢漫的AI人

选一组直接用，或按「自定义模板」改成自己的。**A/B/C 三组是并列方案**，按当次内容场景挑一组，不要混搭。

## 通则

- 字幕 ≤ 6 字，短句、去口语化、有场景感
- 避浮夸词（神器／炸裂／封神／绝了）与绝对化表述
- 白字黑边，所有格子完全一致；标点只用「！」「？」，不用省略号
- 动作写成三幕式：前 2 格起势 → 中间 2 格推进 → 最后 2 格收尾
- 只写上半身动作（见品牌视觉规范第五节）

## 自定义模板

```
字幕：{≤6 字，短句，无浮夸词}
前 2 格：{起势，只写头和手}
中间 2 格：{推进，加一个可见的小道具或符号}
最后 2 格：{收尾，表情变化明显，能接回第 1 格}
道具：{问号 / 灯泡 / 放大镜 / 笔记本电脑 / 手机 / 感叹号，选 1 个}
```

## 文案自检

- [ ] 6 条字幕长度接近，视觉上不会一排挤一排松
- [ ] 没有生僻字、没有标点渲染风险
- [ ] 动作都能靠上半身表达，不涉及腿脚和全身走位
- [ ] 整套语气统一，符合「腾讯算法人」克制、数据感的表达
