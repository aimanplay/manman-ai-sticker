# 生图方式：后端适配

主流程第 1 步用来判断「这次用什么出图」。本 skill 不绑定任何 Agent 或模型：**生图只是产出一张 PNG 的可替换环节**。

## 一、通用探测流程（任何 Agent 都适用）

按这个顺序找，不要一上来就问用户：

1. **当前 Agent 自带的图像生成能力**（内置工具 / MCP / 已装 skill）→ 有就直接用
2. **用户提供的图片 API**（有密钥、有文档）→ 见第二节 A
3. **本机带生图能力的命令行工具** → 见第二节 B
4. **都没有** → 把提示词交给用户，让他在任意生图产品里生成后回传，见第二节 C；已有精灵图的话也可以直接从 `qa_check.py` 起步

**参数一律以该工具自己的文档为准**，不要套用别家的字段名（不同工具可能叫 `image` / `image1` / `reference` / `init_image`）。只需要确认三件事：

| 要确认 | 判断方法 | 影响哪一步 |
|---|---|---|
| 能否传参考图 | 看文档有没有图生图 / reference 参数 | 照片、图片起点必须能传 |
| 能否出真透明 | 看文档有没有 transparent / 抠背景选项；拿不准按不能处理 | 能就跳过 `clean_bg.py`，用 `--bg auto` 切帧 |
| 支持哪些比例 | 看文档的 size / aspect_ratio 取值 | 决定 `--cols` / `--rows` |

比例 → 网格：

| 比例 | 网格 | 帧数 |
|---|---|---|
| 3:2（默认） | 3×2 | 6 |
| 1:1 | 3×3 | 9 |
| 16:9 | 4×2 | 8 |

**输出契约**：不管哪个后端，都要把结果存成当前工作目录里的一张 PNG，文件名按本次编号。后续所有步骤只认文件，不认工具。

验证是不是真透明：

```bash
python3 -c "from PIL import Image; import sys; a=Image.open(sys.argv[1]).convert('RGBA').getchannel('A'); print('真透明' if a.getextrema()[0] < 16 else '不透明')" 图.png
```

## 二、没有内置生图能力时的 A/B/C 备选

只推荐一条最适合的，其余一句话带过，然后停下等用户选。

### A. 用户给一个图片生成 API

问清哪家、哪个模型，把密钥放进环境变量或当前目录的 `.env`，**不要让用户把密钥贴进对话**。

按该家官方文档写调用脚本（模型名、参数名、参考图传法、是否支持透明都以文档为准，不要凭记忆写），输入提示词 + 参考图路径 + 比例，输出 PNG。先跑通一张再批量。按量付费的接口，开跑前告诉用户大概要生成几张。

### B. 调用本机其他生图工具

能执行命令、且装有带生图能力的命令行工具时，用非交互模式把「生成一张图」这一步交给它，花的是用户自己的订阅或额度。参数以本机 `--help` 为准。

- 先单独生成一张试通，确认文件真的落在指定位置、是这次新生成的（看修改时间、打开看内容），再批量
- 每次只派一张图的任务，不要并行发好几个，图容易对不上号
- 工具报「成功」不等于文件对

### C. 用户自己在任意产品里生成

最通用，什么环境都能走：把每一步的提示词写好，用户拿去常用的生图产品里生成，下载后发回来或放进工作目录。

角色设定图的提示词单独先给，用户发回来、确认像了，再把所有精灵图提示词一次给全并编号，让他照着一张张生成、按编号回传。每条写清：传哪张图当参考、比例选什么、背景用纯色那句（不用他判断真假透明）。

**用户发回来的图先过一遍 `qa_check.py` 再往下走。**

## 三、已验证后端档案（附录，仅供参照）

下面是一次完整实跑里记录的参数，用来说明「三件事怎么落到具体字段」。**不是使用要求**：换工具时按该工具文档重新映射，不要照抄字段名。

| 项目 | 那次实跑的取值 | 通用的对应问题 |
|---|---|---|
| 参考图 | 本地绝对路径 + 高保真参数 | 你的工具怎么传图生图参考？ |
| 尺寸 | `1536x1024`（3:2） | 你的工具支持哪些比例？ |
| 提示词改写 | 关掉（防止中文短字幕被改写） | 你的工具会不会自动润色提示词？ |
| 背景 | 要求不透明 + 提示词写纯品红 `#FF00FF` | 能出真透明吗？ |
| 水印 | 参数关不掉，右下角强制加 | 你的工具加不加水印？ |
| 成本 | 约 5–10 额度/张，一套 6 表情约 7 张 | 开跑前告知用户张数与量级 |

那次还观察到：模型把「纯品红」画成渐变紫粉底（由 `clean_bg.py` 归一化解决）；动作写「整个人往后一跳」会变成全身小人并漏画上排字幕。这类现象跟模型有关，换后端时以 `qa_check.py` 的结果为准，不要预设一定会发生。

## 四、换后端时的自检

- [ ] 生成的 PNG 真的落在工作目录、是本次新文件
- [ ] 比例与 `--cols` / `--rows` 对得上，格子接近正方形
- [ ] 真透明底 → 跳过 `clean_bg.py`；不透明底 → 归一化后切帧
- [ ] 有水印 → `clean_bg.py` 清理；无水印 → `--no-wm`
- [ ] 每张都过了 `qa_check.py`
