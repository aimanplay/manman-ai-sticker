# 定角色：三种起点，产出同一张设定图

不管从哪里开始，这一步的产出都是**一张角色设定图**：左边并排正面、侧面、背面三个全身站姿，右边几个头部特写表情。它是后面所有精灵图的唯一参考。

## 通用要求

- 设定图背景用干净的浅灰或真透明；不要求透明，因为它只当参考、不参与切帧
- 画面里不出现任何文字、格子、边框
- **生成后先清掉右下角平台水印再当参考图**：右下角是空白底时用 `clean_bg.py 设定图.png 设定图_干净.png --wm-only`；若角色铺到右下角，改为裁掉右侧 8% 条带，避免矩形填充切断角色
- 出图后给用户确认：像不像、哪些标志要保留、要不要换画风。确认后形象定死

## 一、照片里的人

用户给的是自己或某个人的照片：正脸、五官清楚，最好有帽子、眼镜、发型这类标志。

```
参考图是一位{男生/女生}。把{他/她}画成一张Q版卡通贴纸角色设定图：左边并排是同一个角色的正面、侧面、背面三个全身站姿，右边是四个头部特写表情（开心大笑、震惊、疑惑思考、得意坏笑）。保留{他/她}的标志：{帽子、眼镜、发型、常穿的衣服}，五官和脸型要像参考图里的{他/她}。三头身比例，粗黑描边，干净的平涂上色，表情包贴纸风格，每个形象外有一圈白色贴纸描边。除了角色本身，其余全部是透明背景，不要出现任何文字。
```

不像就改提示词里的标志描述再出一张。想换画风（日漫、像素、黏土、水彩）就替换「Q版卡通贴纸」和「三头身、粗黑描边、平涂」那几句。

## 二、任意一张图

先看这张图是什么，再决定怎么处理；拿不准就用一句话问，同时给出建议。

**已经是一个角色**（手绘小人、吉祥物、已有卡通形象）：默认保留原样和画风，只补全多角度。

```
参考图是一个{简短描述，例如：手绘的蓝色小怪兽}。照着它画一张角色设定图：左边并排是同一个角色的正面、侧面、背面三个全身站姿，右边是四个头部特写表情（开心大笑、震惊、疑惑思考、得意坏笑）。造型、比例、配色、线条和画风都与参考图保持一致，参考图里看不到的角度按同样风格合理补全。除了角色本身，其余全部是透明背景，不要出现任何文字。
```

图不好用（侧脸、糊、被挡、一张图里好几只）时，说清哪里不好、要一张什么样的；没有更好的就用这张，并问清是图里哪一个、哪些特征必须保留。

**宠物／动物照片**：默认 Q 版化，保留毛色、花纹、品种特征。

```
参考图是一只{品种和颜色}。把它画成一张Q版卡通贴纸角色设定图：左边并排正面、侧面、背面三个全身站姿，右边四个头部特写表情。保留它的{毛色、花纹、耳朵形状、项圈}，要让主人一眼认出。粗黑描边，干净的平涂上色，贴纸风格，白色贴纸描边。除了角色本身，其余全部是透明背景，不要出现任何文字。
```

**物品／食物／logo**：问用户要拟人化（加眼睛嘴巴手脚，最适合做表情）还是保持原样只让它动。拟人化就把上面「已经是一个角色」那条换成「把参考图里的{物品}拟人化成卡通角色，加上眼睛、嘴巴和小手小脚，保留形状和配色」；保持原样可跳过设定图，直接用原图进精灵图那一步。

## 三、什么图都没有

只有一句描述时，按描述设计角色：

```
设计一个{角色描述}，画成一张卡通贴纸角色设定图：左边并排正面、侧面、背面三个全身站姿，右边四个头部特写表情。{外形、配色、标志性配饰}。粗黑描边，干净的平涂上色，贴纸风格，白色贴纸描边。除了角色本身，其余全部是透明背景，不要出现任何文字。
```

描述太「随便做个可爱的」就先给 3 个方向各一句话让用户挑，再出图。

## 生图工具不能传参考图时

只有纯文字起点还能做：设定图出来后，把角色写成一段固定描述（物种或身份、体型比例、每个部位颜色、标志配饰、画风），后面每张精灵图都把这段完整贴进提示词，代替「参考图是……」那句。角色在帧间会有出入，先跟用户说明。
